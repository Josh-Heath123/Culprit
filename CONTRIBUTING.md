# Contributing

Thank you for looking. Culprit is maintained by one person, Joshua Heath
([`AUTHORSHIP.md`](AUTHORSHIP.md)).

## What is welcome now

- **Issues:** a bug, a wrong finding, a limit you hit that
  [`docs/LIMITS.md`](docs/LIMITS.md) does not state, a question. Open one on
  GitHub.
- **Security reports:** privately, as [`SECURITY.md`](SECURITY.md) says, not
  in a public issue.

## Code contributions are not accepted yet

**Outside code contributions are not accepted until the contributor
agreement below has been read by a lawyer.** Please do not open a pull
request with code or documentation; it will be closed unmerged, however
good it is. This will change, and this file will say so when it does.

## The contributor agreement

When contributions open, each contributor will be asked to sign an
individual contributor licence agreement before a pull request is merged.

| | |
|---|---|
| Template | **Harmony Individual Contributor License Agreement (HA-CLA-I), version 1.0** (2011-07-04), from Project Harmony: <https://www.harmonyagreements.org/agreements.html>. The licence form: you keep the copyright in your contribution and grant a licence to it; it is not an assignment. |
| "We" / "Us" (the recipient) | Joshua Heath |
| Project | Culprit |
| Outbound licence (section 2.3) | **Option Five:** the contribution may be licensed under any licence, including copyleft, permissive, commercial or proprietary ones, in addition to the licences of the material it is part of ([`LICENSING.md`](LICENSING.md)). |
| Media licences | Not chosen yet. |
| Governing law (section 6) | Not chosen yet: for the lawyer's review. |
| How to sign | Not open yet. |

**Why Option Five.** It keeps the owner able to offer Culprit under licences
other than the AGPL, as well as under it, which is what keeps a hosted or
commercially licensed Culprit possible. A contribution would always also be
available under the licence of the code it is part of.

The template's text is Project Harmony's, under the Creative Commons
Attribution 3.0 Unported licence; it is linked here rather than copied, and
the agreement a contributor signs will be that text with the choices above.

## Licences of what is here

Every file states its licence ([`LICENSING.md`](LICENSING.md), REUSE 3.3).
A file added to this repository needs an SPDX header, or an entry in
[`REUSE.toml`](REUSE.toml) when it cannot hold a comment; `just lint` fails
otherwise.
